Spectrum Barometer

The router barometer project started because spectrum won't let you port forward on the routers they give you anymore and I wanted to see if I could find a way around it and while I may not have, I found a way to scrape the barometer readings from the router as long as you were connected to its network thanks to some person on GitHub who has reverse engendered the board itself to get the credentials. I then promptly got distracted deciding to learn how to make a real cli tool out of it instead of just a script like I usually make and after that learning flask to give it a real web UI that you can use so if you choose you would need very little knowledge on how to use the terminal. When I finally remembered to write this it's been on V2.2.2 for a few months, and I'm pretty happy with it as it is so unless something changes its probably not getting more updates but that's fine its simple, easy to use and cross-platform, everything I wanted out of it.

Garfbounce
